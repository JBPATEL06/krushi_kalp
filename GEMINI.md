# 🎨 2️⃣ The Design Gravity Shield (Token Enforcement Law)

### Absolute Rule:

> No raw values. Only tokens.

All UI must consume:

* Color tokens
* Typography tokens
* Spacing tokens
* Radius tokens
* Elevation tokens
* Motion tokens
* Component tokens

Forbidden forever:

Colors.blue
fontSize: 17
EdgeInsets.all(13)
BorderRadius.circular(7)
Duration(milliseconds: 173)
Everything flows from:

AppTheme.colors.primary
AppSpacing.md
AppTypography.bodyLarge
AppRadius.md
AppMotion.normal
If a value is not tokenized → it does not exist.

* Who mutates it?
* What triggers rebuild?
