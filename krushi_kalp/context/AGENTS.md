# Project Map: Industry-Standard Flutter Application

## 🎯 Project Overview
- **Goal:** Scalable, high-performance cross-platform application (Web & Mobile).
- **Core Focus:** Maintainable codebase, high-speed data fetching, and simultaneous responsive compatibility.

## 🛠 Tech Stack
- **Framework:** Flutter 3.27+ (Stable).
- **State Management:** Riverpod 3.0 (AsyncValue / Notifiers).
- **Database:** Isar (NoSQL) for high-speed local caching.
- **Networking:** Dio + Retrofit (Type-safe API).
- **Navigation:** GoRouter (Declarative with Deep Linking).
- **Responsiveness:** Responsive Framework (Auto-scaling & Breakpoints).

## 🔌 Connected MCP Skills
- **flutter-tester:** Autonomous UI verification and logic testing.
- **stitch-ui:** Visual-to-Code translation for high-fidelity UI design.
- **dart-mcp-server:** Static analysis and deep code refactoring.

## 📂 Architecture Map
- `lib/features/`: Feature-first organization (UI, Logic, and Data in feature folders).
- `lib/core/`: Global constants, base services, and theme configurations.
- `lib/shared/`: Reusable widgets, shimmers, and design system components.
