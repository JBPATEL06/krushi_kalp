## ⚠️ Important Rules

- **Never commit `key.jks` or `key.properties` to Git** — add both to `.gitignore`
- If published to **Google Play Store**, the release keystore is **permanent** — you cannot change it
- If only for **sideloading/testing**, keystore can be regenerated (old installed APKs won't update via install)
- Debug keystore is machine-specific — Google Sign-In in debug mode requires the debug SHA registered in Firebase
- Always keep at least **2 offline backups** of `key.jks`
